pkglist

The Problem

You have programs installed from distro repos with rpm, then more from flatpaks, then from node, a little bit from bun and so on, don't you wish you could see all of them in one place and really figure out what is eating all your disk space?

Checking each source individually and trying to deduce what exactly is taking up so much space from dependency descriptions is so time consuming it's

The Solution

Clean TUI meaning terminal user interface application that reads and lists all of the packages in one application, accounting for dependencies and dependees. Doubles as a CLI tool for those who love grepping and piping to text files.

Follows obviosity rule of interaction design; all the actions available at any given moment are always visible. Don't have to remember what button does what. Made with Rust for performance, smaller binary, and easier build process (thanks cargo).

Licensed with GPLv3.

RenamerFX

The Problem

You have a lot of files to rename and many different operating systems to work with and can't be arsed to scribble scripts all the time.

The Solution

Cross-platform graphical renamer. Simple as.

Made with JavaFX as a bit of a proof-of-concept exercise on using familiar separation of logic and UI, with UI presentation entirely written in FMXL, a JavaFX HTML-like XML syntax with its own CSS dialect.
